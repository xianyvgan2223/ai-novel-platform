# 使用指南

三个角色先分清楚：

| 角色 | 是什么 | 干什么 |
| --- | --- | --- |
| **手机 App** | 你原来的 Flutter 应用 | 生产数据；设置里有「数据同步」和「导出/导入数据库」 |
| **Web 服务** | `web/server`，一个 Node 进程 | 存放数据、提供接口、托管网页 |
| **浏览器** | Chrome / Edge 打开的那个页面 | 看数据、改数据、备份 |

**手机和 Web 的同步有两条路**：直接点同步（推荐），或者用 .db 文件来回搬（备用）。

---

## 一、启动服务

```powershell
cd web/server
npm start
```

输出长这样，**记下「手机请填」那一行**：

```
本机访问:  http://localhost:3210
手机请填:  http://192.168.43.5:3210   ← 手机 App / 浏览器用这个
            http://10.33.7.251:3210   （以太网）
以下为虚拟网卡，手机连不上，忽略即可:
            172.30.0.1  (vEthernet (WSL))
            192.168.116.1  (VMware Network Adapter VMnet1)
```

服务默认监听 `0.0.0.0`，所以同一局域网内的手机可以直接访问。

> 数据存放在 `web/server/data/`，三个文件：`deepseek.db`（主库）、`novel.db`（小说游戏库）、
> `sync.db`（同步元数据）。**备份就是把这三个文件拷走**。

### 想先随便点一点看看效果

```powershell
cd web/server
npm run seed                            # 生成演示数据到 data-demo/
$env:DATA_DIR='data-demo'; npm start    # 用演示数据启动
```

演示数据写在 `data-demo/`，**不会碰你的真实数据**。

## 二、直接同步（推荐，不用导文件）

### 前提

- 手机和电脑连**同一个 Wi-Fi**，或者**电脑连手机的热点**
- 电脑上服务已经启动（第一步）

### 步骤

1. 手机打开 App → **设置** → 找到「**数据同步**」→ 点进去
2. 在「服务地址」里填第一步记下的那个地址，例如 `http://192.168.43.5:3210`
3. 点「**测试连接**」，看到「连接成功 · deepseekapp-web-sync …」就说明通了
4. 点「**立即同步**」

看到绿色的「同步完成」以及拉取/上传条数，就成功了。

### 它到底做了什么

1. 先**拉取**：服务端上被网页改过的内容，会更新到手机
2. 再**上传**：手机上的数据（含新增的对话、小说章节、跑团记录）推到服务端
3. **API Key 不在同步范围内**（既不上传也不会被覆盖），没必要把密钥送到网页上

同步是幂等的：两边内容一样时服务端会按内容哈希判重，不会重复写入、也不会把数据搞乱。
所以「想同步就点一下」完全没问题，多点几次不会出问题。

### 注意事项

- 同步完成后建议**返回首页重新进入**，列表才会显示最新数据（页面上的列表不会自动刷新）
- 如果同一行在手机和网页上都被改过，**保留服务端（网页）的版本**，并把这次冲突记录在
  网页「同步与备份 → ④ 同步冲突记录」里，可以事后去看
- 第一次打开新版本 App 时会自动做一次数据库升级（只新增两张同步用的簿记表），
  **不会动任何对话或作品数据**

### 连不上怎么办

按顺序排查：

| 检查项 | 说明 |
| --- | --- |
| 地址填对了吗 | 必须用「**手机请填**」那一行。`172.30.x`、`192.168.116.x`、`26.x` 这类是虚拟网卡（WSL / VMware / 加速器），手机连不上 |
| 手机和电脑同网段吗 | 电脑连手机热点时，电脑地址通常是 `192.168.43.x` 开头 |
| Windows 防火墙 | 最常见的原因。用**管理员** PowerShell 执行一次即可放行：<br>`netsh advfirewall firewall add rule name="deepseekapp sync" dir=in action=allow protocol=TCP localport=3210` |
| 服务真的在跑吗 | 电脑浏览器打开 `http://localhost:3210` 能看到页面就说明服务正常，问题在网络 |

> 提示：电脑连手机热点时，Windows 常把这个网络识别为「公用网络」，防火墙会更严格。
> 上面那条命令就是针对这种情况的。

## 三、用文件搬运（备用方案）

网络不方便时，或者只想单向搬一次时用这条。**App 不需要任何同步配置**。

### 手机 → Web

1. **手机**：设置 → 「**导出数据库**」→ 得到 `deepseek_backup.db`
2. **传到电脑**：微信文件传输助手 / USB / 网盘都行
3. **网页**：左侧「同步与备份」→「① 导入 App 数据」→ 目标库选 `deepseek.db`、
   方式选**合并** → 选择文件

### Web → 手机

网页「同步与备份」→「② 导出回手机」→ 下载 `.db` → 传手机 → App 设置 →「导入数据库」→ 重启 App。

### ⚠️ 这条路的三个坑

**坑 1：API Key 会丢。** 导出时「清空 API Key」开关**默认是开的**，导回手机后 App 会失去配置。
→ 导出前把它**关掉**（显示成「保留 API Key」）。只有要把文件发给别人才需要开。

**坑 2：App 的导入是「全量覆盖」。** 官方提示原文是"导入将覆盖当前所有数据"。
→ 顺序必须是：**手机导出 → 网页改 → 立刻导回手机**。别在导出之后又在手机上聊，那些新对话会被覆盖。

**坑 3：`novel.db`（小说游戏模块）导不进来。** App 的「导出数据库」只导出 `deepseek.db`。
这个库只能用上面的**直接同步**。

## 四、在网页上能做什么

| 页面 | 能做什么 |
| --- | --- |
| **总览** | 各模块数据量、同步服务状态、每张表的行数与最近变更时间。点任意一行跳到该表 |
| **对话会话** | 按标题/末条消息/摘要搜索，双击一行看完整对话 |
| **会话详情** | 阅读完整对话，AI 回复渲染 Markdown，思考过程可展开，联网搜索来源可点开 |
| **数据浏览** | **最有用的一页**：24 张表全部可浏览、搜索、排序、编辑、新增、删除 |
| **同步与备份** | 导入导出、设备与同步水位、冲突记录 |

几个典型用法：

- **批量改小说章节**：数据浏览 → 选「写小说 · 章节」→ 找到章节 → 编辑 → 保存
- **导出某段内容**：会话详情里选文字复制；或数据浏览双击该行 → 「复制 JSON」
- **清理数据**：数据浏览里删除（删会话会**连带删除**它的全部消息，这是表结构决定的）
- **查设定**：数据浏览 → 角色扮演各表，看世界书条目与角色记忆

## 五、日常怎么用最省心

- **平时**：正常用手机 App，想在电脑上整理时点一次「数据同步」
- **整理完**：再点一次同步，或在网页上直接改完即可（网页的改动下次同步会拉到手机）
- **换电脑 / 重装**：把 `web/server/data/` 三个文件拷回去就行；手机上「重置同步状态」后重新同步会重新比对一遍

## 六、让别人（或手机浏览器）也能访问

同一 Wi-Fi 下的手机/平板用「手机请填」的地址就能打开网页界面。

⚠️ 一旦要跨网络访问（端口映射、内网穿透、放到公网服务器），**必须开启鉴权**：

```powershell
cd web/server
Copy-Item .env.example .env
# 编辑 .env，设置 API_TOKEN=一串足够长的随机字符串
```

然后在手机 App 的「数据同步 → 高级选项 → 访问令牌」里填同一个值；
前端网页则在 `web/app/.env.local` 里填 `VITE_API_TOKEN` 并重新构建。

否则任何人都能读写你的全部数据。

## 七、常见问题

| 现象 | 原因 / 解决办法 |
| --- | --- |
| 手机「测试连接」失败 | 见第二节的排查表（八成是防火墙或填了虚拟网卡地址） |
| 网页顶部红色「无法连接同步服务」 | 服务端没启动。`cd web/server` 后 `npm start`，再点右上角刷新 |
| 打开是一片 0，没有任何数据 | 还没导入。走第二节同步一次；或先 `npm run seed` 看演示 |
| 同步后手机上还是旧数据 | 返回首页重新进入页面（列表不会自动刷新） |
| 同步很慢 | 数据量大时第一次同步会久一些。之后只有变化的部分需要传 |
| 导入时提示「数据库版本 vXX 高于 Web 端支持的 vYY」 | App 升级了表结构但 Web 端还没跟上。按 `数据模型.md` 第 6 节更新 `schema.js` |
| 导出下载没反应 | 浏览器拦截了下载，允许该网站下载即可 |
| 端口 3210 被占用 | `$env:PORT='3211'; npm start`，手机端同步地址也要跟着改成 3211 |
